# CSCI-Final-Project-Kees

# How to Use
As this is a .md file a reader that shows formatting will allow for better reading.

## Running
run ./FinalProject

First Select Size

**Small**: 6x6, D3, 11 rolls

**Medium**: 8x8, D4, 15 rolls

**Large**: 10x10, D5, 19 rolls

### Menu Navigation
1. **Roll**: Roll the dice 
2. **Bounty**: View the current Treasure amount
3. **Save**: Save the current game to a custom file
4. **Exit**: Exits the game
5. **View Saves**: Shows a list of currently saved files, Unfortunatly there is no native way to view these files.

**Coordinate Input**
When prompted input a targeted coordnate to dig. Input coordnates with the letter first then the number(A1, B5, Z10). The dig spot will be replaced with '+' and if you found treasure it will inform you.  

## Features
- **Dynamic Board Sizing** The boards go from Small to Large with scaling diffuclty and treasure.
- **Coordinate Systems** There is a coordinate system that tracks places gone as well as treasure locations. 
- **Save Systems** There is a system in place that allows for saving of the gamestate with custom file names
- **Clean UI** The UI is cleaned with every move but also not so much it becmoes flashy, only the parts that are being changed get reloaded.
- **Colored Map** The map has a color system where green is the ground and brown is the dug spots.

## Limitations
Due to time constraints I did not implemnt loading from the save files.
